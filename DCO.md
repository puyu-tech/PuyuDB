# Developer Certificate of Origin

PuyuDB requires a **Developer Certificate of Origin (DCO), version 1.1** sign-off
on each contribution commit, including documentation changes. Read the certificate
at [developercertificate.org](https://developercertificate.org/) before signing.

The sign-off records your certification under the DCO; it is not a CLA or a
copyright assignment. Original contributions are accepted under the same
[Apache-2.0 license](LICENSE) as the project (inbound = outbound). You retain your
copyright.

Use your own name and email in your Git identity, then sign off a commit with:

```sh
git commit -s -m "Clarify contributor guidance"
```

Git adds a `Signed-off-by` trailer using that identity. A DCO sign-off is separate
from cryptographic commit signing. Do not sign on someone else's behalf or certify
material you do not have permission to contribute.

A sign-off does not replace the source, license, and notice information required
for copied, adapted, generated, or dependency material. See
[CONTRIBUTING.md](CONTRIBUTING.md).
