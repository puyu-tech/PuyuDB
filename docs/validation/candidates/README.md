# Common candidate evidence

Generated evidence for comparison revision 2. The run-specific CSVs are
byte-for-byte copies of standalone workload stdout, not manually normalized
tables. Each directory has a sanitized manifest identifying inputs and hashes.
Raw stderr/commands and full native history artifacts remain in the local
result directories named by the comparison report; they can contain local paths.

`seeds.csv` retains each native full-history seed artifact as hexadecimal, along
with byte lengths and hashes. These are observations for the pinned candidate
profiles, not a frozen PuyuDB seed or storage format.

See [the comparison report](../I02-candidate-comparison.md) for methodology,
derived summaries, limitations, and the separate PuyuDB-fit evidence matrix.
